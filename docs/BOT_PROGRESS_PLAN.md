# Durable progress experiment plan

Owner: Boop compact experimental backend. Released v4 and graphics are out of scope.

## Hypothesis and sequence

The early all-kitten loop cannot be repaired by adult deployment alone. Reward
useful kitten development before a ready-to-complete pair exists. Then ablate
adult retention risk: deployed cats that the opponent can immediately eject
should not receive full durable-progress credit.

0. Following the user's concern, prioritize an independent canonical-rules search
   oracle before weight experiments: both actors, all root action values, depths
   1–5, no TT/history/compact transitions, plus principal variations. Test actor
   handling at pending graduation nodes and antisymmetric evaluation.
1. Add a pure, color-symmetric geometric feature breakdown. No hidden history,
   random ties, rule changes, additional uncharged transition searches or new
   search engine. Keep existing compact evaluator and work charging.
2. Development candidate: existing eight-cat value plus 10 per deployed kitten,
   plus 2 per open three-cell window containing exactly one own kitten and no
   opponent, capped at 12 windows. Kitten development tapers with total owned
   adults: multiply by (8 - ownedAdults) / 8. A setup is not a forced promotion.
3. Retention ablation: development candidate minus 24 for each distinct own cat
   directly ejectable by an opponent cat placement, and minus 8 for each distinct
   own kitten directly ejectable by any available opponent placement. Count a
   target once, not once per attacking square. This is geometric exposure, not
   a proof of the opponent's best move; terminal wins still dominate.
4. Targeted tests: promotion runway, inventory taper, blockers, unavailable cat
   stock, kitten immunity to kittens, both colors and D4 geometry, immutability,
   terminal win priority, repeated decisions/work limits.
5. Revisit all four diagnosed loops with both sides upgraded, original work
   allowances, 80 further placements. Report losses as well as escapes. These
   are diagnostic training positions, not independent strength evidence.
6. Equal-work screening: each candidate versus compact v4-equivalent control,
   30k each, 12 paired openings, seeds 2000–2011, original 180-placement cap.
   Choose only a candidate scoring at least 60%, with greater than 50% in each
   six-pair half. If both qualify choose the higher paired score; tie goes to
   simpler development candidate. Otherwise stop without promotion.
7. If selected, freeze source hashes BEFORE a fresh 24-pair confirmation on seeds
   2100–2123, equal work. Require at least 60% and positive score in each half;
   report paired uncertainty and do not claim a reliable rating. A successful
   confirmation nominates further release engineering, not automatic live use.

No retuning on screening/confirmation seeds. Preserve all negative results.
No head-to-head wall-clock claims from concurrent jobs. Plan committed with final
results; this document is written before launching either screening batch.
